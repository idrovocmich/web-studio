# Brand repository template

Files to copy into each **private** brand repository. Nothing here contains client data.

- `.github/dependabot.yml`: weekly grouped pull requests for `@idrovocmich/*` engine updates.

A brand repository holds `brand.json` (validated by `@idrovocmich/brand-contract`), its logos
and fonts, and the site. See the root README, section "Using the engine in a brand repository".
